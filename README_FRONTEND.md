# Frontend Asistente Financiero

Frontend React simple para interactuar con la API de `main.py`.

## Instalación

1. Abrir terminal en `frontend`
2. Ejecutar `npm install`
3. Ejecutar `npm run dev`

## Uso

- El frontend corre en `http://localhost:5173`
- Asegúrate de que el backend de FastAPI esté activo en `http://localhost:8000`
- El formulario hace POST a `/analizar` y muestra una conversación estilo chat.
